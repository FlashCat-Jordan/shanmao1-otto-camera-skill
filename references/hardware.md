# 硬件与安全

> 不同批次/不同摄像头板的引脚可能不同。改 GPIO 前先核对板子丝印和用户提供的 `config.h`，不要凭本文猜。

## 板级

`otto-robot` 摄像头版：

- ESP32-S3，16MB Flash；
- ST7789 240×240 屏幕；
- 六舵机：左腿、右腿、左脚、右脚、嘴巴、脖子；
- I2S 麦克风 + I2S 扬声器；
- 可选摄像头：OV2640 / OV3660 / GC2145；
- 可充电锂电池。

## 舵机

| 关节 | 典型 GPIO | 安全范围 |
|---|---:|---|
| 左腿 | 5 | 0～180，正常 75～105 |
| 右腿 | 43 | 0～180，正常 75～105 |
| 左脚 | 6 | 0～180，正常 80～100 |
| 右脚 | 44 | 0～180，正常 80～100 |
| 嘴巴 | 4 | **45～60，绝对不能超过 60** |
| 脖子 | 7 | **45～180，135 为正前方** |

- 嘴巴是单向上开，超过 60° 会顶坏机械限位；
- 脖子左右极限必须按装配确认；
- 上电时不要用手硬掰舵机；
- 拆装舵机前先断电；
- 动作异常先检查舵机方向、限位和供电，不要直接加大幅度。

## 摄像头

车牌/模组可能不同：

- OV2640：PID `0x2640` / `0x2626`
- OV3660：PID `0x3660`
- GC2145：PID `0x2145`

摄像头方向由 `hmirror` / `vflip` 和预览旋转共同决定。GC2145 在不同批次可能需要 180° 补偿。不要同时改传感器方向和预览旋转，否则会双重翻转。

## 音频

- 双工 I2S：麦克风和扬声器共用采样率；
- 摄像头版当前常用 **16kHz 输入 / 16kHz 输出**；
- 不要把输出改成 24kHz 而输入仍是 16kHz，否则双工麦克风会异常；
- 麦克风信号过大时不要盲目加增益，先看是否削顶。

## 电源

- 电池供电，带充电检测；
- 完整烧录不会改变硬件，但会清 NVS；
- 舵机堵转/卡住会大电流发热，测试动作时注意；
- 不要用 GPIO 直接给舵机供电。

## 安全测试顺序

1. 架空或垫高机器人；
2. 先测小幅度、低速动作；
3. 确认每个关节方向正确；
4. 再落地测试行走；
5. 最后测试远场语音和摄像头。
